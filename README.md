# Регистратор 360 — релизы

Готовые сборки приложения «Регистратор 360» (`io.github.adyachenko.avmdvr`): запись камер кругового обзора на магнитоле Geely Okavango.

## Что нужно

- Geely Okavango с прошивкой Lunaris.
- Root через Magisk: приложение ставит и запускает регистратор через `su`.

## Первая установка

1. Скачать `avmdvr-<версия>.apk` из [последнего релиза](https://github.com/adyachenko/avm-dvr-releases/releases/latest).
2. Установить: `adb install avmdvr-<версия>.apk` или через файловый менеджер на магнитоле.
3. Открыть «Регистратор 360» и разрешить root в окне Magisk. Регистратор установится и начнёт запись.

## Обновления

Приложение само проверяет этот репозиторий раз в 6 часов. Новая версия появляется в «Настройки → Регистратор» с кнопкой «Установить». Можно включить автоматическую установку: тогда обновление ставится, когда выключено зажигание.

## Отчёты об ошибках

Приложение отправляет разработчику отчёты об ошибках и сбоях: версии, модель магнитолы и прошивки, первые 8 символов VIN (марка и модель), логи регистратора. Координаты, видео и полный VIN не отправляются. Отправку можно выключить в «Настройки → Регистратор».
